# Sinopen — Sinoka's Handwritten Font

![](./image.png)

This is my first custom font, so there might be a few rough edges or errors. Issues and pull requests are always welcome!

## About
Created by generating a base typeface with [Ductus](https://ductus.sorenblank.com/) and refining the glyphs in [FontForge](https://fontforge.org/).

Due to technical limitations, font files are provided only in .ttf format.
